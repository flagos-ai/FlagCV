# 数值容差策略

图像算子不能用统一相对误差验收。整数算子根本不应有误差，而插值算子的舍入差异在
任何实现间都存在。统一阈值要么放过真 bug，要么把正常实现差异判为失败。

因此容差**逐算子类别**定义。

## A 级：位精确

结果必须与参考实现逐字节相同。适用于不含浮点中间量的整数算子。

按位运算、固定阈值二值化、元素比较、翻转/九十度旋转/转置、边界填充、查表映射、
中值滤波（整数）、腐蚀膨胀（整数）、非零计数。

## B 级：±1 LSB

允许每通道最多 1 个最低有效位偏差，源于不同实现的舍入点选择。

重采样（最近邻/双线性）、仿射透视变换、色彩空间转换（整数输出）、加减与加权混合
（整数输出）、图像金字塔、均值与高斯模糊（整数输出）。

## C 级：相对误差

浮点输出按相对误差验收：`32F` 用 `1e-5`，`16F` 用 `1e-2`。

梯度与通用卷积（浮点输出）、双边滤波、幅值相位、范数与均值、积分图（大图放宽至
`1e-4`）、模板匹配。

## D 级：结构一致

输出是离散结构而非像素值，需专门比较器。

- **边缘检测**：允许单像素位移，要求边缘像素集在 1 像素邻域内互相覆盖率 ≥ 99%
- **特征点检测**：允许顺序不同，要求 top-N 交集比例 ≥ 95%
- **轮廓提取**：按面积排序后比较

## 两处陷阱

**区域重采样的权重规则必须明确固定。** 缩放比为非整数时权重分配有多种合理解释，
按"平均池化"的直觉实现会系统性偏离，不是 ±1 LSB 能覆盖的量级。该规则必须在参考
实现中固定并在算子支持矩阵注明。

**浮点累加顺序影响可复现性。** 规约算子的并行实现与串行参考末位必然有差异，容差
需随尺寸放宽；且规约树形状必须固定，不能依赖运行时线程调度，否则同一输入多次执行
结果不同。
